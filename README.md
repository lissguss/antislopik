# Антислопик

Скилл, который находит и правит нейрослоп в русскоязычном тексте.

Рубленые фразы, «не X, а Y», физические глаголы при абстракциях, кальки с английского, пустые уточнители — всё это и не только вычищает сей скилл.
Собран на текстах 2026 года — на том, что модели пишут сейчас, а не на маркерах вроде «в современном мире», которые давно устарели.

Скилл правит стиль и синтаксис. Логику, структуру и фактуру текста он не трогает.

## Что делает антислопик

Работает в двух режимах:

- **Fix** — по умолчанию. Находит конструкции, показывает таблицей, что и на что меняет, отдаёт очищенный текст.
- **Detect** — если попросить не исправлять («только найди», «просто покажи, что тут не так»). Отдаёт таблицу флагов без правок.

Внутри — алгоритм из девяти шагов. Модель проходит текст несколько раз, на каждом
проходе ищет один тип дефекта.

## Установка

### Claude.ai и десктопное приложение

1. Скачать папку `antislopik` из этого репозитория (кнопка **Code → Download ZIP**, потом достать из архива только папку antislopik)
2. Заархивировать папку antislopik: правый клик → «Сжать» на macOS, «Отправить → Сжатая ZIP-папка» на Windows. Внутри архива должна лежать **папка** `antislopik` с файлом `SKILL.md`, а не голый `SKILL.md`.
3. В Клоде: **Settings → Capabilities → Upload skill** (в части интерфейсов — «Customize → Skills → +»), выбрать архив с папкой antislopik.

Нужен платный тариф Claude и включённое исполнение кода. Скиллы, загруженные таким образом,
работают и в чате, и в Cowork.

### Claude Code, Cursor и другие IDE

```bash
git clone https://github.com/USERNAME/antislopik.git
cp -r antislopik/antislopik ~/.claude/skills/
```

`~/.claude/skills/` — личные скиллы, доступны во всех проектах.
`.claude/skills/` внутри репозитория — только для этого проекта.

После копирования перезапустить сессию. Проверить: `/skills`.

### Без скачивания

Если не хочется тянуть файлы с чужого гитхаба — открыть
[`antislopik/SKILL.md`](antislopik/SKILL.md), скопировать текст целиком,
вставить в Клод и попросить: «сделай из этого скилл».

## Как пользоваться

Скилл вызывется сам, если попросить почистить текст от нейрослопа. Явные триггеры:

```
прогони через антислопик
почисти нейрослоп в этом тексте
только найди нейрослопные конструкции, не исправляй
```

Работает с любыми форматами текста.
